# Ui Home

Client site using `@workspace/ui` and the `ukrainian-institute` brand theme.

## Commands

```bash
pnpm --filter ui-home dev       # local site
pnpm --filter ui-home build     # production build
pnpm --filter @workspace/ui storybook # component reference
```

## Pages

Add screens under `src/pages/`. Compose them from `@workspace/ui/components/*`,
`@workspace/ui/blocks/*`, and `@workspace/ui/layout/*`.
