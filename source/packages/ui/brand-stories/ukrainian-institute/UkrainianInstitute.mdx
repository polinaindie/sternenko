# Український інститут — Insight UA reference

Tokens for the **Український інститут** brand are calibrated against
[Insight UA](https://insight.ui.org.ua) — the Institute's cultural discovery
platform. Brand colours and typeface come from the
[official identity](https://ui.org.ua/ui-logo/); spacing, breakpoints and type
scale are measured from Insight's production CSS.

Select **Brand → Український інститут** in the toolbar (default) and open
**Overview → Insight Layout** or **Blocks → Insight Programme → Fedir Yakymenko**.

## Breakpoints (Insight UA)

Insight uses three main cut-offs. They align closely with our skeleton tokens:

| Insight UA | Our token | Value  | Typical use on Insight                          |
| ---------- | --------- | ------ | ----------------------------------------------- |
| `≤767px`   | base      | mobile | 12px gutters, 14px base type, single column     |
| `≤1023px`  | `md`      | 768px+ | 24px gutters, 64px header, 2-column grids       |
| `≤1028px`  | `lg`      | 1024px+| 40px gutters, 3-column waterfall, wide hero     |
| desktop    | —         | 1440px | `.container { max-width: 1440px }`              |

Our `lg` (1024px) is one step past Insight's 1028px tablet-landscape token —
close enough for shared components without a custom breakpoint.

## Layout

| Token               | Insight UA value | Notes                                      |
| ------------------- | ---------------- | ------------------------------------------ |
| `--container-max`   | `90rem` (1440px) | `.container`, `.events-container`          |
| `--page-gutter`     | `0.75rem` (12px) | mobile padding                             |
| `--page-gutter-md`  | `1.5rem` (24px)  | tablet (`≤1023px` rules)                   |
| `--page-gutter-lg`  | `2.5rem` (40px)  | desktop `.container` padding               |

`Container` applies all three gutters: base → `md:` → `lg:`.

## Typography

Insight sets `letter-spacing: -0.04em` on headings and scales type down on
mobile by setting `html { font-size: 14px }` below 768px.

| Role        | Desktop              | Mobile (≤767px)        |
| ----------- | -------------------- | ---------------------- |
| Body        | 16px / 1.375         | 14px / 1.214           |
| H1 (hero)   | 73–80px, bold        | 38–54px                |
| H2          | 36px                 | 20px                   |
| H3          | 32px                 | 24px                   |
| Nav links   | 18px bold            | 14px bold              |
| Footer copy | 20px                 | 16px                   |

Heading tracking (`-0.04em`) is applied globally when
`data-theme="ukrainian-institute"` is active.

## Shape

The brandbook specifies **sharp corners** (`--radius: 0`). Insight's marketing
UI uses small radii on buttons (6px) and cards (4px) — mapped as
`--product-radius` for programme/article blocks.
