# Спільнота Стерненка — застосування брендбуку

Візуальна мова БФ «Спільнота Стерненка» вивчена з місячних звітів фонду та його
проєктів (Шахедоріз, Небесний/Поточний русоріз, ReDRONE, FPV-закупівлі). Це
**дворівнева система**: спільний фундамент фонду (жовтий + чорний, Murs Gothic,
геометрична зірка) і проєктні акценти поверх єдиного шаблону звіту.

Тема активна за замовчуванням (`data-theme="sternenko-fund"`). Дивись
**Foundations → Overview**, **Report → \*** та **Blocks → Monthly Report**.

## Кольори

Фундаментальна палітра живе у
`packages/tokens/themes/sternenko-fund.css` і читається компонентами лише через
семантичні токени — бренд-кольори ніде не зашиті в компоненти.

| Brandbook     | Hex       | Токен                          |
| ------------- | --------- | ------------------------------ |
| Yellow Energy | `#FFD62E` | `--primary`, `--ring`, `--accent` |
| Black         | `#1E1E1E` | `--foreground` / dark `--background` |
| Grey          | `#898989` | `--muted-foreground`           |
| White         | `#FFFFFF` | `--background`                 |

**Патерн:** темне полотно + один насичений акцент + чорний текст на акценті.
Без градієнтів і тіней (`--shadow-card: none`).

## Палітри проєктів

Кольори стягнуті (просемплені) безпосередньо зі скріншотів місячних звітів і
винесені в `packages/tokens/palettes/sternenko-fund-report-palettes.css`. Кожна
палітра — це накладка через атрибут `data-report-palette`, що перевизначає лише
семантичні токени, тож будь-який `Report/*` компонент пере-скінюється без правок.
Дивись **Foundations → Project Palettes** і **Blocks → Monthly Report**
(Potochnyi, Sky Cutter).

| `data-report-palette` | Проєкт            | Полотно            | Акцент             | Другорядний        |
| --------------------- | ----------------- | ------------------ | ------------------ | ------------------ |
| `shahedoriz`          | Шахедоріз / звіт  | чорний `#1E1E1E`   | жовтий `#FFD62E`   | —                  |
| `nebesnyi`            | Небесний русоріз  | чорний `#1E1E1E`   | cyan `#59CBE7`     | —                  |

| `potochnyi`           | Поточний русоріз  | темно-зел. `#1B241A` | олива `#829474`    | pale `#EAEDE6`     |

Застосування:

```tsx
<MonthlyReportBlock palette="nebesnyi" {...props} />
// або вручну на будь-якому контейнері:
<div data-report-palette="potochnyi"> ...Report/* ... </div>
```

## Типографіка

Шрифт **Murs Gothic** підключено в
`packages/ui/src/styles/sternenko-fund-fonts.css`; кожен крій — окрема родина на
вазі 400 (без faux-bold, `font-synthesis: none`).

| Роль у звітах                    | Крій             | CSS / токен            |
| -------------------------------- | ---------------- | ---------------------- |
| Hero-числа (`3 013`, `$7,2 МЛН`) | Wide Black       | `--font-display-black` / `h1` |
| Назви проєктів (`ШАХЕДОРІЗ`)     | Wide Dark        | `--font-display-dark` / `h2` |
| Підзаголовки секцій              | Narrow Dark      | `--font-subheading-dark` / `h3–h4` |
| Мітки під числами                | Key Regular/Light | `--font-sans`          |

Правила: ALL CAPS для заголовків і дат; пробіл як роздільник тисяч (`2 861`);
`letter-spacing: -0.02em`; стиснений `line-height` (0.9 для заголовків).

> Примітка: файли `.woff2` Murs Gothic поки відсутні в репо — до їх додавання
> у `packages/ui/src/assets/fonts/murs-gothic/` дисплейні крої падають на
> системний sans, але компоненти вже посилаються на правильні родини.

## Композиція

Усі звіти — це **bento-сітка** з однаковою інформаційною архітектурою: верхній
ряд (дата · назва проєкту · медіа), середина (1–2 hero-метрики + вторинні), низ
(розбивка / прогрес плану · логотип). Шаблони сітки:

| Патерн                      | Де видно                  |
| --------------------------- | ------------------------- |
| 2-col split (55/45)         | ReDRONE, Поточний русоріз |
| 4-corner + центральна смуга | звіт по техніці           |
| Left stack + right image    | Шахедоріз, Небесний       |
| Full dashboard              | донати, FPV-закупівлі     |

Відступи між модулями (8–12px) дає темний фон як «рамку». Сітка та брейкпоінти —
зі спільного `base.css` і **не змінюються per brand**, лише кольори/радіус.

## Форма: два контексти радіусу

Сайтовий UI Стерненка — гострі кути (`--radius: 0`, flat), але звіти/дашборди
використовують скруглення. Тому введено окремі токени в `base.css`:

- `--radius-report: 0.75rem` (12px) — картка звіту
- `--radius-report-lg: 1rem` (16px) — hero / медіа

Report-компоненти посилаються на них (`rounded-[var(--radius-report)]`), тож
лишаються скругленими навіть коли сайт гострий.

## Компоненти звіту

| Компонент                     | Призначення                          |
| ----------------------------- | ------------------------------------ |
| `ReportCard`                  | bento-контейнер (tone: accent/contrast/card/muted/outline) |
| `DisplayMetric`               | велике число + мітка (uk-UA grouping) |
| `CurrencyMetric`              | `$7,2 МЛН` (compact) / `₴210 572 345` |
| `ReportDateStamp`             | маркер періоду «Звітуємо за …»       |
| `ProjectTitle`                | назва проєкту в рамці + іконка        |
| `MetricBar` / `MetricBarGroup` | вертикальний bottom-fill стовпчик    |
| `MonthlyReportBlock`          | зібраний layout звіту                |

Усе тримається на семантичних токенах, тому зміна теми пере-скінює звіти без
правок компонентів.
